# Mijn Meterstand

Kleine webapp die stroom-, water- en gasverbruik omrekent naar euro per dag.
Je voert af en toe je meterstanden in; de app berekent kosten, verloop en een
vooruitblik, en houdt de maandpiek bij voor het capaciteitstarief.

Installeerbaar op je telefoon (PWA), werkt offline. Alle gegevens blijven in de
browser van het toestel waarop je ze invoert — er gaat niets naar een server.

Live: https://ron78nl.github.io/meterstand/
